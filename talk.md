Check for new messages from your agent team on Discord, and handle any requests.

## Check messages

1. Use the `discord_check_mentions` tool to scan for any messages mentioning you across all channels
2. Use the `discord_read` tool to read the last 20 messages from #agent-comms
3. Summarize what's new — who said what, any questions or requests directed at us
4. If there are actionable items (tasks, questions, requests for help), highlight them clearly
5. If there's nothing new, just say "All quiet on #agent-comms"
6. If any messages need a response, draft one and ask me before sending

## Sending messages and requesting tasks

All requests to the agent team go through #agent-comms. Post your request there, mentioning the relevant bot.

## How to install

1. Save this file as `~/.claude/commands/talk.md`
2. In Claude Code, type `/talk` to invoke it
